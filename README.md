# Git Branching Homework

## Описание проекта
Проект был сделан для изучения работы веток.

## Использованные ветки
| Ветка | Что делал | Как попала в main |
|---|---|---|
| feature/profile | модуль профиля | merge локально |
| feature/subjects | список дисциплин | merge локально |
| feature/report | итоговый отчёт | Pull Request |
| experiment/broken-idea | тестовая идея | удалена без merge |

## Коммиты
-Создание проекта и основной структуры
-Доабвление ветки profile и ее содержимого
-Доабвление ветки subjects и ее содержимого
-Доабвление ветки report и ее содержимого
-Объединение ветки main и report
-Доабвление ветки broken idea и ее содержимого
-Удаление ветки broken idea
-Обновление README



## Скриншоты
- граф веток до merge;
- результат merge;
- созданный и закрытый Pull Request;
- финальная ветка main на GitHub.

## Вывод
Ветки можно создавать от разных веток, их можно удалять. При локальном удалении ветки она не удалиться в облаке (ну на гитхабе). Можно объеженять ветки прямо в самом гитхабе.
